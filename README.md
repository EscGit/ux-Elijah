# j01: Using steam for the first time

Being huge on video games as a hobby I kind of expected to eventually move away from mainly consoles and try desktop. Especially since the majority of games aren't released on console or can't be adapted because of mouse and keys. So to start I needed a way to download games so I needed an application. With Desktop there is a sort of monopoly with this service being Steam. Going into Steam I had three main user goals in mind: how do I search for a game, how do I wishlist games to try later, and where could I find my game library.

<img width="2205" height="1185" alt="Screenshot 2026-09-20 143409" src="https://github.com/user-attachments/assets/f4e61165-e8de-4e86-b364-f2c56033aad5" />

Each one of my goals worked together since I was trying to find Atomic Heart when I first saw it. Luckily searching for a game was very simple, as it's on the front page. While the main Steam page is overloading with different games and options and the occasional popup for sales, I did not have an issue looking up the game. The search bar was also great, as I could search up games by categories if I wanted to mainly find a fighting game, racing, or platformer, etc. This is a good example of visibility, since the search function and its filtering options are easy to locate and understand just by looking at them, without needing to dig around.

<img width="1585" height="104" alt="Screenshot 2026-09-20 143500" src="https://github.com/user-attachments/assets/11e01033-b596-42de-8a04-2f7533dcc619" />

So when I searched up the game I was quickly taken to the page and could easily find reviews, what system requirements I needed, and if it supported controllers. The store page was great with showing me media of the game with screenshots and trailers, giving me plenty of context before committing to anything.

Then came the task of wishlisting the game so I could get it later. I did not have much issue with this either, since it was easily on the store page when I scrolled down a bit. I also saw an option to follow the developers and to ignore this game or anything similar from popping up.

<img width="1289" height="106" alt="Screenshot 2026-09-20 144009" src="https://github.com/user-attachments/assets/1833482a-ba7e-4bb6-8e8e-141a37cc27a9" />


So wishlisting games is easy, but my main issue was looking for that wishlist afterward. I went back to the main store page first. For the first time, the store page is so packed that I get lost easily. I tried the top options first: Steam, View, Games.

<img width="287" height="217" alt="Screenshot 2026-09-20 144157" src="https://github.com/user-attachments/assets/f3f58374-de16-41dd-8040-4b8d6c58f1bd" />

<img width="250" height="269" alt="Screenshot 2026-09-20 144107" src="https://github.com/user-attachments/assets/2546cee4-519e-4364-87d2-414914c5d346" />


These did not help me at all. Steam was only to change my account I was using or to show I'm offline. I thought I was closer with View, since it showed Library and Hidden Games. However, Library only showed me games I had already bought on my account, and Hidden Games were games I wanted to hide from my library. This is where my mental model, my own idea of how the wishlist should be organized and accessed, stopped matching the site's actual conceptual model, the way Steam's designers actually structured the navigation. I expected a "wishlist" concept to be filed somewhere near "library," since to me they're related, but the system didn't map them together.

<img width="747" height="625" alt="Screenshot 2026-09-20 144302" src="https://github.com/user-attachments/assets/33f3f652-63ec-4aff-b870-e01c31f17ab5" />



So then I tried two more options I saw on the main page, which were in larger text: Library and my username. I already knew Library sent me straight to the games I already have, but I thought the dropdown menu would have a wishlist option.

<img width="2199" height="1253" alt="Screenshot 2026-09-20 144414" src="https://github.com/user-attachments/assets/e8cdcb8c-db8e-4c2c-9a50-c1a86cd9d987" />


With that being a bust again, I tried clicking on my username, and still nothing, only my profile page with my achievements and friends' games. It wasn't until I had a closer look at the main page that I saw there are two ways to access my wishlist: one in the dropdown menu from the Store tab, and one on the main page itself.

<img width="132" height="231" alt="Screenshot 2026-09-20 150032" src="https://github.com/user-attachments/assets/5d7efe0c-7eb7-44f6-96b4-f465775915d4" />


Once I actually found it, the lack of a clear affordance (nothing about the Store tab visually signals "your wishlist lives here") was really the whole source of my confusion. There was also no feedback anywhere earlier in my search, like a "did you mean wishlist?" prompt or highlight, to tell me I was getting warmer or colder as I clicked around.
